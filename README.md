## Lab Structure

Every lab is maintained as a self-contained project:

```text
Labs/
└── Lab-XX-Topic-Name/
    ├── README.md
    ├── topology.png
    ├── lab-file.unl
    ├── configurations/
    ├── screenshots/
    ├── documentation/
    └── video/
```

Each lab may include:

- A clear overview and learning objectives
- Vendors, devices, and technologies used
- Network topology and IP addressing
- Device configurations
- Verification commands and test results
- Troubleshooting notes
- Screenshots and walkthrough video
- Downloadable documentation and EVE-NG lab files

## Portfolio Scope

The portfolio will include focused labs and full enterprise-scale scenarios using technologies and platforms such as:

- Cisco IOS and IOS XE
- MikroTik RouterOS
- Fortinet FortiGate
- Routing and switching
- Network security and VPNs
- Monitoring and network visibility
- Python-based network automation
- Multi-vendor enterprise designs

## Approach

The focus is on practical evidence: every completed lab should show the topology, configuration, validation results, and lessons learned—not only the final commands.
